# Caltrop Creations

A responsive static portfolio for a technical animator. Built with HTML, CSS, vanilla JavaScript, and original SVG mechanical illustrations. No package installation, build process, API keys, or external asset services are required.

## Run locally

From this directory:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Open the server in a browser. The site can also be hosted by any static web host; deploy `index.html`, `styles.css`, `script.js`, and `assets/` together.

## Content

- Filterable concept gallery with accessible project detail dialogs
- Mechanical gear animation with pause and reduced-motion support
- Expandable technical field notes
- Responsive mobile navigation
- Contact and published-work links to the existing ArtStation profile

The gallery is explicitly labeled as illustrated concept studies. Replace those studies with actual project assets and descriptions when available. Contact uses ArtStation; there is no form backend or invented email address. External links require Internet access; the site itself works offline.
